# Anonymity Checklist

This model-only package is prepared for anonymous review.

Excluded from this directory:

- training launchers and job submission scripts
- dataset adapters and data roots
- saved weight paths, experiment records, and logs
- usernames, machine names, hostnames, storage names, and local filesystem paths
- project-specific framework wrappers outside the model definition

Included in this directory:

- shared GeoWeave dependency scorer and selected-token attention
- Pi3-style model entry
- VGGT-style model entry
- compact configuration dataclasses
- minimal usage documentation
