# Experimental

This directory contains experimental configurations for VGGT model training and evaluation. These configs are used for testing new features, hyperparameters, or model architectures before they are integrated into the main training pipeline.

Key features of experimental configs:
- Custom dataset configurations
- Modified model parameters
- Alternative training strategies
- Debug and development settings

Note: These configs may not be fully tested or optimized for production use.
